# Edge AI Runtime
## Run AI Models at the Edge — Zero Latency

Deploy AI models that run in the browser. No API calls. No latency. Pure edge computing.

**Live:** https://edge-ai-runtime.vercel.app

---

## What This Demonstrates

### Browser-based AI
- WebAssembly inference
- WebGPU acceleration
- ONNX Runtime Web

### Zero Latency
- No API calls
- No network requests
- Instant responses

### Privacy-First
- Data stays on device
- No cloud processing
- GDPR compliant

---

## Getting Started

```bash
git clone https://github.com/cyber-lazer-mermicorn/edge-ai-runtime.git
cd edge-ai-runtime
npm install
npm run dev
```
